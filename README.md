# Wawa's Photo Booth 📸✨
A nostalgic, authentic Y2K aesthetic photo booth web app.

---

## 📁 ไฟล์ทั้งหมดในโฟลเดอร์นี้ (Files in this folder)
โฟลเดอร์ `Wawa` นี้บรรจุไฟล์ทั้งหมดของ Photo Booth ครบ 100% พร้อมอัปโหลดขึ้น Vercel / Netlify ได้ทันที:
- `index.html` - หน้าเว็บหลัก
- `css/` - สไตล์ธีม Y2K Aesthetic
- `js/` - โค้ดกล้อง WebRTC, Canvas ฟิลเตอร์ 28 แบบ, กรอบรูป 50 แบบ, สติกเกอร์, ลายมือเขียน
- `assets/` - ภาพตัวอย่างโมเดล
- `vercel.json` - คอนฟิกสำหรับ Vercel
- `_redirects` - คอนฟิกสำหรับ Netlify
- `start-photobooth.bat` - ดับเบิ้ลคลิกเพื่อเปิดทดสอบในคอมพิวเตอร์ทันที

---

## 🚀 วิธีอัปโหลดขึ้น Vercel (ง่ายสุดๆ ไม่ต้องลงโปรแกรมหรือพิมพ์คำสั่งใดๆ)

เนื่องจากเครื่องของคุณยังไม่ได้ติดตั้ง Node.js หรือ Git ให้ใช้วิธีผ่านหน้าเว็บ Browser ได้เลยครับ:

### ขั้นตอนที่ 1: อัปโหลดขึ้น GitHub (ใช้เวลา 1 นาที)
1. เข้าเว็บ [github.com](https://github.com) (หากยังไม่มีบัญชี ให้สมัครฟรี)
2. กดปุ่ม **"+"** มุมขวาบน -> เลือก **"New repository"**
3. ตั้งชื่อ Repository เช่น `wawa-photobooth`
4. ติ๊กเลือก **Public** แล้วกดปุ่มเขียว **"Create repository"**
5. ในหน้าที่เปิดขึ้นมา จะมีข้อความสีฟ้าเขียนว่า **"uploading an existing file"** ให้คลิกที่คำนี้
6. ลากไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ในโฟลเดอร์ `Wawa` ไปปล่อยในช่องบนหน้าเว็บ GitHub
7. รอแถบอัปโหลดเสร็จ เลื่อนลงมาด้านล่างกดปุ่มเขียว **"Commit changes"**

### ขั้นตอนที่ 2: เชื่อมต่อและ Deploy บน Vercel
1. เข้าเว็บ [vercel.com](https://vercel.com) แล้วกด **Sign Up** หรือ **Log In** ด้วยบัญชี **GitHub**
2. เมื่อเข้าสู่หน้าแดชบอร์ด กดปุ่ม **"Add New..."** -> เลือก **"Project"**
3. จะเห็น Repository `wawa-photobooth` ที่เพิ่งสร้าง ให้กดปุ่ม **"Import"**
4. ในหน้าถัดไป **ไม่ต้องแก้ไขการตั้งค่าใดๆ เลย** (ระบบจะรู้ว่าเป็นเว็บสำเร็จรูป HTML/JS ทันที)
5. กดปุ่ม **"Deploy"**
6. รอ 10-20 วินาที จะมีพลุขึ้นฉลอง 🎉 และได้ลิงก์เว็บจริง เช่น `https://wawa-photobooth.vercel.app` นำไปแชร์หรือเปิดในมือถือถ่ายรูปได้ทันที!

3. เว็บจะออนไลน์ทันที พร้อมลิงก์ HTTPS ฟรี ใช้งานกล้องมือถือได้สมบูรณ์แบบเช่นกันครับ!
